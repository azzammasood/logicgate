# LogicGate First Run

## For engineers
1. Sign up with role **Engineer**.
2. Open **Definitions** and create a metric.
3. Set source table and conditions; check the **Pseudocode** tab.
4. **Publish** when ready.

## For stakeholders
1. Sign up with role **Stakeholder**.
2. Request changes via **Request Review** on a definition you own.
3. Track status under **Change Requests**.

## Team
Use **Stakeholders** to invite members by email.
